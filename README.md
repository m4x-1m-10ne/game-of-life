# Игра «Жизнь» (Conway's Game of Life)

Веб-приложение на Flask, реализующее классическую клеточную игру «Жизнь». Проект выполнен в рамках курса по Flask на платформе Stepik.

## Возможности

- Игровое поле 20×20.
- Кнопки управления: **Start** (запуск эволюции), **Stop** (пауза), **Step** (один шаг), **Clear** (очистить поле), **Random** (случайное заполнение).
- Отображение текущего поколения (счётчик).
- Автоматическая остановка при вымирании всех клеток.
- Случайная генерация новой конфигурации.

## Дополнительные задания (⭐)

1. **Счётчик поколений** – отображается номер текущего поколения.
2. **Отслеживание мёртвых клеток** – если все клетки умирают, эволюция останавливается.
3. **Исправление нового мира** – кнопка Random создаёт случайное заполнение поля.

## Технологии

- Python 3.6+
- Flask
- Jinja2
- Bootstrap 3 (стили)
- Сессии Flask для хранения состояния поля
